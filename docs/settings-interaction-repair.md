# 设置交互与组件材质修复

2026-10-19，本地分支 `codex/task-records-redesign`。

| Before | After | Why |
| --- | --- | --- |
| 有修改时关闭只触发页脚确认，保存或选择文件时所有关闭入口被禁用 | X、关闭、Escape 和遮罩直接关闭；保存与关闭独立 | 用户随时可以回到工作台，不被迫应用设置。 |
| 关闭后整个设置组件卸载，草稿和在途保存状态随之消失 | 常驻内存会话与可卸载的 dialog 分开，重新打开继续编辑 | 不丢草稿，也不保留关闭后的焦点锁、遮罩和光学副本。 |
| 保存错误、忙碌状态与关闭混在同一路径 | 保存单独校验与防重复；失败保留草稿，成功清除提交密钥；提供撤销更改 | 操作结果明确，保存失败不影响退出。 |
| 被关闭的文件选择器仍可能回填结果 | 关闭使本次选择失效，迟到结果不更新草稿 | 避免重新打开后被旧操作覆盖或锁住。 |
| 设置快照更新可能与当前草稿混淆 | 干净会话跟随实际设置；未应用草稿不会被实时状态覆盖 | 保留编辑意图，撤销时恢复最新已保存配置。 |
| 阅读和历史内容使用近纯白实色底 | 使用低强度半透明浅色调与细边界；实色模式保留完整底色 | 让内容融入工作台玻璃，避免嵌套大白纸。 |
| 菜单默认白色混合 .60，滑块使用白色混合 .83 的 thumb；thumb 折射还被乘以 .45 | 应用适配将菜单映射为 panel、滑块为 slider-thumb、开关拇指为 selected | 复用上游已有的通透配置，让内部控件也能表现背景折射。 |

草稿只保存在当前页面的内存，刷新页面会清除。输入的 API Key 不进入 localStorage 或 sessionStorage，提交成功后从草稿清空。外观选项仍即时生效，不受业务设置的保存与撤销影响。

材质适配只在原渲染器读取几何时选择已有配置，不改变工厂语义 DOM 或组件手势，不修改上游源码、着色器、场景采样、分层呈现或绘制循环，不新增 WebGL context、模糊层或逐帧 React 更新。Lens 仍折射自身场景与已合成的玻璃，不采集网页正文像素。
