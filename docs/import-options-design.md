# 导入参数稳定布局

2026-10-20 根据用户最终要求，恢复“处理方式”下方原有双列参数布局。应用 apple-design 与 emil-design-eng 的空间一致性和禁用状态原则，保留原版 Lens 选择器、开关、玻璃材质与手势。

| Before | After | Why |
| --- | --- | --- |
| 参数根据处理方式挂载或移除，其余控件上下移动 | 语言、规格、翻译和服务始终保持在原位置；当前不适用的项变灰并真正禁用 | 切换方式时无需重新寻找控件。 |
| 关闭翻译后服务整块消失 | 服务保留，关闭翻译时禁用选择器 | 保持表单高度并保留已选服务。 |
| 本地文件不显示处理方式 | 处理方式保留并禁用，下载规格也禁用 | 在线/本地切换维持一致的参数排列。 |
| 每次参数变化触发整块退出、进入动画 | 参数直接更新可用状态 | 避免反复淡出、位移和延迟生效。 |
| 服务切换或无服务时提示行增加、减少 | 固定一行状态文字，始终保留服务选择器与配置入口 | 切换服务、开关翻译不会挤动提交按钮。 |
| 极长服务名称撑开下拉菜单内部 | 菜单文本允许收缩并单行省略，完整名称仍在语义标签中 | 从文本布局解决横向溢出。 |

三个处理方式、在线/本地来源、语言、下载规格、翻译开关及服务选择继续使用原业务回调。仅下载禁用语言和翻译；生成文字禁用下载规格；保存并转写允许二者；本地文件允许转写、翻译，禁用链接处理方式和下载规格。切换来源时保留原有 downloadOnly → transcribe 的归正行为，其他参数不会因禁用被清空。

外层 fieldset 的 busy 禁用仍覆盖参数与配置入口。配置翻译服务入口平时始终可用，即使没有服务或翻译已关闭。只有来源输入内容保留原有过渡，并使用 215px 的最小高度稳定参数起点；参数区不再使用内容切换动画。

类型检查与前端构建通过；服务端业务未在此调整中修改。界面验证采用隔离 HTTP/SSE 模拟数据及 DOM/ARIA/事件与尺寸检查，不使用截图、图像识别或像素读取，不执行真实媒体任务。
