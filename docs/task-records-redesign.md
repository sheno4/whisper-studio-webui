# 任务记录重设计

本地分支：`codex/task-records-redesign`。使用 apple-design 与 emil-design-eng 整理任务区，保留导入、任务、阅读三个工作区域及原版 Lens 材质与组件。

| 修改前 | 修改后 | 原因 |
| --- | --- | --- |
| 名称、状态、进度分散在多个块中 | 每条记录使用一张完整玻璃卡片，名称、来源与时间、处理方式与状态依次排列 | 让任务信息按阅读顺序集中呈现。 |
| 小字号名称、重复的完成进度与固定高度空槽 | 14px 名称最多两行；仅进行中任务显示原版 Lens 进度 | 提高可读性，完成记录与历史记录不再占据空白进度区。 |
| 选择区域与操作入口尺寸不一致 | 独立的 44px 操作按钮固定在卡片右上方 | 保持操作对齐，不嵌套按钮，不缩放整张记录。 |
| 历史清空占用来源切换行；筛选提示预留空白 | 清空按钮放到历史列表标题旁，提示只在需要时显示 | 让分段选择器保持完整宽度，减少无效留白。 |
| 搜索输入缺少独立清除入口 | 搜索图标与清除按钮，清除后保留输入焦点 | 连续查找任务更直接。 |
| 旧窄屏规则恢复固定进度占位 | 各窗口尺寸使用同一套自然高度卡片 | 避免不同尺寸下重新出现空槽和错位。 |

保持现有当前任务/历史切换、内容过渡、来源滚动位置、搜索、筛选、分页、固定显示当前查看记录及所有操作回调。没有修改服务端、业务 hooks、API 或上游 Lens 源码；没有新增渲染器或逐帧 React 更新。
