# Whisper Studio · Lens 原版前端

本次重写开发于 `codex/lens-native-rewrite`。前端采用 [ruiqichenbiec/design-systems 的 Lens](https://github.com/ruiqichenbiec/design-systems/tree/7a424c93b9be13cf835b91ea67495fec2ec0584e/lens/lab/design-system)，固定提交 `7a424c93b9be13cf835b91ea67495fec2ec0584e`。2026-10-18 核对远程 HEAD 与该提交一致。

完整 portable package 的 48 个文件与根 MIT LICENSE 原样保存在 `src/renderer/vendor/lens-native/`；`SHA256SUMS` 可核对原件，`UPSTREAM.md` 说明应用适配。当前构建真正调用其 `createGlassSystem`、`GlassRenderer`、`JellyController` 和组件工厂，并直接加载原版 `tokens.css` 与 `components.css`。

| 下拉框 | 原版 `createComponent('menu')` 的触发器、弹出层、材质及交互；薄适配补齐 combobox/listbox、受控选项、表单、动态禁用和输入法安全的 typeahead。 |

大面板和标题栏保持静止。可拖动的是分段胶囊、开关及滑块，不添加面板拖动。宽屏为导入、任务和结果三个并列区域；中等窗口保留并列阅读区，窄屏自然展开，面板不会随记录切换重新挂载。

当前样式入口只有原版 tokens/components、应用 `lens/workspace.css` 和未知进度/无障碍适配 `lens/progress.css`。旧 `studio/*.css` 与 `styles/rdev.css`、`select.css`、`segments.css` 等叠加样式不进入新构建。rdev、Studio、liquidGL 等历史源文件保留溯源，但不进入当前渲染路径。

## 功能边界

现有工作流继续使用相同业务 hooks 和 API：多链接提取、本地多选/拖放、实时队列、并行任务状态、取消/重试、历史搜索/筛选/分页、原文/译文/双语/日志、阅读搜索、八种文字/字幕导出、全部输出文件定位、翻译服务及加密密钥、模型准备/取消/重试、诊断、确认和通知。

设置的草稿、跨分区状态、未保存确认、保存锁和密钥提交后清空继续保留。此次没有修改服务端、转写/翻译/下载逻辑、API 路径或响应结构。

## 材质与性能

采用上游 Thick 材质、真实 Snell 折射、色散、Fresnel/高光、距离场形变和同一场景的 ping-pong 合成。浅色使用原 Aurora，深色使用原 Ocean；已有壁纸通过官方 artwork 回调绘制，加载失败保留此前场景。

Lens 折射采样自己的场景画布及已经合成的玻璃，不采集任意网页 DOM、视频或第三方页面。正文与表单文字继续由浏览器渲染，因此不宣称可以折射任意 DOM 文字或完整复制原生 iOS 26。

每个工作台只有一个 WebGL2 context。场景尺寸取可见视口，默认使用真实 devicePixelRatio，不再限制在 DPR 1.5 或约 1080p 的总像素；长文档不分配整页纹理。16,777,216 像素的基础预算覆盖普通物理 4K/5K 显示，较大屏幕可提高至 33,554,432 像素，并遵守显卡实际纹理、绘制缓冲和视口尺寸限制。实际分配失败时按固定面积减半并记住成功上限，不按逐帧耗时反复改变清晰度。跨屏或浏览器缩放时同步换算高光指针坐标。

背景闲置动画与默认声音关闭，活动任务仍保留原版进度反馈。动态组件移除时释放对应 Jelly body、监听器和 ResizeObserver，任务更新不重建整个渲染器。

设置、确认框和原生 popover 菜单使用同一渲染结果的分层呈现，材质与文字一起进入各自层级；菜单解除外部滚动区裁切，内部滚动仍保留。原版光学循环每个透镜只绘制一次，在层间使用原 COPY 程序保存已完成结果；弹层可见时增加一次底层场景 blit、每层之间的 COPY 和最后的底层恢复。只复制本机 Lens 画布，没有网页截图、DOM 光栅化、额外着色器或第二个 WebGL context。

弹层底层纹理与场景同尺寸，普通菜单/设置的 2D 呈现画布与场景保持相同像素密度。极端超大或过多弹层、实际分配失败时统一降低共享场景质量，避免只有弹层模糊。关闭弹层、实色模式、隐藏页面及卸载时释放，不存在弹层时没有这组额外缓冲或 COPY；扩容之前先释放旧弹层缓冲。呈现适配不建立自己的动画循环。高分辨率会增加显存与填充量，像素预算不等同于硬件帧率承诺。

界面材质明确选择“液态玻璃 / 实色”，玻璃由应用绘制；旧的“跟随系统”材质值迁移为玻璃，已选实色保持不变。“系统配色”只控制明暗主题。高对比度、减少动态效果和 WebGL 降级继续可用。链接输入区使用 12px 圆角和多行文本内边距，避免沿用搜索胶囊的轮廓。原版源码保持不改，节点生命周期、视口尺寸和现有语义 DOM 适配位于 `src/renderer/lens/`。

## 本轮审查修复

| 修改前 | 修改后 | 原因 |
| --- | --- | --- |
| 多套控件样式和材质链路叠加 | 当前入口只使用 Lens 原版组件、tokens 和同一渲染器 | 统一尺寸、层级、交互和光学来源。 |
| 菜单定位通知会同步再次进入自身，且动画缩放参与定位 | 定位期间保留重入保护，以布局尺寸定位，菜单自然宽度与 left 解耦 | 消除已复现的递归报错和尺寸反馈。 |
| 弹出文字进入顶层，光学结果仍受下面面板阻挡 | 将同一次原版光学结果呈现在对应弹层中 | 保持文字、材质和层级一致，保留菜单内部滚动裁切。 |
| 长菜单的画布随内容滚出可见区 | 画布抵消宿主滚动量，覆盖 client 视口，样式只在变化时更新 | 防止滚到菜单底部后出现材质缺口，避免持续重绘。 |
| 开关在拖动中被禁用时可能停在未提交位置 | 取消手势并回到当前语义值 | 禁用期间不提交配置，外部受控值仍生效。 |
| 下拉选项重建丢失焦点，原生表单重置可能与受控显示值分离 | 在焦点未被外部接管时恢复新触发器；原生 reset 后同步受控值 | 保留异步选项和表单契约。 |
| 当前任务/历史等内容直接替换，来源滚动提前跳转 | 同一内容层先淡出再进入，显示内容切换时恢复其滚动位置 | 任务来源、搜索/筛选/分页、记录详情、阅读模式/格式、导入方式/选项及设置分区使用同一可打断过渡；面板保持挂载。 |
| 分段 ResizeObserver 反复 snap，属性变更重建组件 | 仅首次有效测量 snap，后续保留原生弹簧速度；标签/badge/禁用原位更新 | 鼠标切换和尺寸改变仍能看到胶囊流动，拖动中不覆盖 x/y，轮询不重播内容动画。 |
| 约 2MP 场景和弹层在高分辨率显示器被放大 | 真实 DPR、同密度弹层、实际资源失败后固定降级 | 避免正常 2K/4K/5K 下的主动低分辨率渲染。 |

内容过渡采用 WAAPI，仅改变 opacity 与 2–3px 位移：默认退出 60ms、进入 120ms；减少动态效果时为 120ms 纯淡化。快速反向切换从当前呈现值重定向，用户控件即时响应，React 不逐帧更新。每个实际动画阶段通知原 Lens 光学时钟，并在结束后刷新最终几何，避免玻璃停留在中途。复制与查找始终对应可见正文。
